## 新洲汇总置顶 + 综合评分模块（2026-08-11 晚第二阶段）
### 用户要求
1. 把"新洲区·本月汇总"（3 个 KPI 卡）放到页面**最上面**
2. 新增**综合评分模块**，按图2 打分规则（5 个模块 × 权重），分别给出得分

### 改造内容
1. **DB 层**：
   - 新增 `score_rule` 表（indicator + label + weight + period + base_value + challenge_value + good_is_high + scoring + criteria + sort_order）
   - 种子数据：5 个模块，权重合计 18（satisfaction 6 + workorder 3 + complaint 3 + fttr 3 + terminal 3）
   - `db/database.py` 新增 `get_score_rules` / `compute_module_score(rule, current)`：
     - good_is_high=1（越高越好）：current ≥ challenge 满分；current ≤ base 零分；中间线性
     - good_is_high=0（越低越好）：反向
2. **后端 `/api/scoring`**（routes/api.py）：
   - 从 5 个看板 `kpis` 实时提取当前值（不走快照，直接调 `COLLECTORS[view]`）：
     - satisfaction：综合满意度（kpi.value）
     - workorder：100 - 平均装机效能（反推"质差率"近似）
     - complaint：从 `complaint_repository.latest_complaint_report()` 读 `city_rate`（真实最新值）
     - fttr：平均连接率 / 100（标准化为 0~1 小数，与 base/challenge 对齐）
     - terminal：故障率 %
   - 返回 `{modules: [{...rule, current, score, ratio, status}], total_weight, total_score, total_ratio}`
3. **前端 `summary.js`**（新模块）：
   - `loadXinzhouSummary()`：从 `/api/complaint_chart` 取新洲汇总（district_daily 优先，回退 latest.districts）
   - `loadScoring()`：从 `/api/scoring` 渲染 5 张评分卡（当前值/基准值/挑战值/进度条/得分）+ 总得分汇总
4. **前端 `dashboard.html`**：
   - main 顶部插入 `<section id="top-summary">`：新洲汇总卡 + 评分模块卡
   - `<script src="summary.js">` 注入（在 complaint_upload 后、app.js 前）
5. **`app.js`**：`init()` 优先 `Promise.allSettled([loadXinzhouSummary, loadScoring])`；"刷新全部"按钮也同步刷新顶部
